# Monochrome Developer Pass

Redesign sisi depan dan belakang kartu berdasarkan referensi ID card vertikal. Palet off-white, charcoal dan abu-abu; foto miring terpisah dari hero, panel tipografi vertikal, nameplate besar, QR GitHub. Tidak menggunakan logo institusi palsu. Interaksi drag, spring dan flip dari versi sebelumnya dipertahankan; CSS 3D + SVG + JS, bukan WebGL.
